# Referências externas

Resuma aqui, em arquivos curtos, a documentação de terceiros que o agente precisa e que não está no repositório (ex.: `fastapi-notas.md`). O que o agente não enxerga não existe para ele. Cite a fonte e a data no topo de cada arquivo. Não cole texto protegido por direitos autorais: escreva com suas palavras.
